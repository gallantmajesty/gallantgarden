# Discord community guide — Focus Lily

## Why Discord first
Discord is where students already live. A server gives Focus Lily a home base for
feedback, bugs, study-buddy matching, and eventually your own community culture —
before you have to build chat inside the app.

## Phase 1 — bare-bones server (launch week)
Start SMALL. A 5-channel server is fine:

- `#welcome` — rules + how to start studying in 60 seconds (link to focuslily.com)
- `#announcements` — feature drops, downtime, launch updates (only you post)
- `#feedback-and-bugs` — one thread per major suggestion; you answer within 48h
- `#study-rooms` — voice channels named by realm (Library / Train / Lofi Café) —
  this IS the product, people hang out and study together here
- `#chill` — general chat

Use Discord's built-in onboarding (Questions tab): "What do you study?" — it gives
people a 1-click join and tells you who's active.

## Phase 2 — week 2-4
- Add `#screenshots` (people LOVE showing their forest/trees — cheap free marketing)
- Add `#roadmap-voting` with a single poll per week (1 question only)
- Enable community server perks + use Discord's native apps/roles sparingly:
  roles = `Library Dweller`, `Train Rider`, `Note Keeper` earned via @-mention or
  emoji-reaction on #welcome

## Safety rules — you are 16, take this seriously
- **Never share personal info** — no school, city, age specifics in public channels
- **Mods:** only add people you know IRL for now. Later, mod = someone active 3+
  months. Give mods zero admin powers until Discord's onboarding has been running
  a while — start with "Manage Messages" only
- **Pinned moderation policy:** one warning, then kick, then ban. Write it once, pin it
- **Never take money in Discord** — all payments go through the app's Stripe/Razorpay
  flow, never "send to this PayPal"
- Turn on Discord's explicit-content filter at the server level (Settings → Safety)

## Growth tactics (free)
- Every Friday: "Forest Friday" — post the top 3 screenshots of the week from #screenshots
- Every bug report gets an emoji reaction + reply within 24h → word spreads
- Invite the "study with me" crowd: many students run Discord study streams; reach out
  to 5 small streamers and offer nothing but a real product to demo — honesty wins
- Link the Discord from the app: Settings → Community → Join Discord (add a small link
  in the landing nav + profile screen)

## What NOT to do
- Don't create 20 channels — empty channels kill servers
- Don't DM-blast members with ads
- Don't promise features; say "noted, added to roadmap" instead
